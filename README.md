# 三角洲口琴自动化

> 给《三角洲行动》里的口琴小游戏写的一个 **Windows 自动演奏器** —— 选一首歌，按开始，程序替你按键。

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

## 这是什么

游戏里的口琴小游戏只有 **8 个白键**（没有黑键），想弹一首完整的流行歌很吃力。
这个程序把简谱转成「键盘 + 鼠标修饰键」的按键序列，自动发给游戏，**像打字一样把整首歌弹完**。

- 纯 Python 标准库，无第三方依赖（试听合成可选装 numpy）
- 图形界面，选曲、调速度、看进度
- 曲库可自建、可分类管理，内置 38 首

---

## 键位规则（核心，必须先看懂）

口琴只有 8 个音，全都对应键盘上的 8 个键：

| 游戏音 | do | re | mi | fa | sol | la | si | do' |
|---|---|---|---|---|---|---|---|---|
| 键盘 | `Z` | `X` | `C` | `V` | `B` | `N` | `M` | `,` |

没有黑键，所以 **升号 / 降号 / 跨八度** 全靠鼠标辅助键：

| 鼠标 | 作用 | 含义 |
|---|---|---|
| **左键** | 降调 | 在基准音基础上下行一个八度 |
| **中键** | 半音 | 在基准音基础上 +1 个半音（黑键） |
| **右键** | 升调 | 在基准音基础上上行一个八度 |

每次发声 = **按住鼠标修饰键 + 按住键盘键 → 保持时值 → 全部松开**。
例如 `G#5` → 键盘 `B` + 中键 + 右键；`C#4` → 键盘 `Z` + 中键；`B3` → 键盘 `M` + 左键。

## 简谱书写规则

曲库 `songs.json` 里每首歌的 `jianpu` 字段用简谱文本描述，解析规则如下：

| 记号 | 含义 |
|---|---|
| `1` ~ `7` | 音阶（do ~ si） |
| `0` | 休止符 |
| `#` / `b` | 升号 / 降号，**只影响紧挨着的下一个音** |
| `'` | 高八度（可叠写多个） |
| `,` | 低八度 |
| `-` | 时值 +1 拍 |
| `_` | 时值减半 |
| `.` | 附点（时值 ×1.5） |
| `~` | 时值 +1 拍 |
| `()` | 括号内整体降八度 |
| `[]` | 括号内整体升八度 |

> **括号是作用域语义**：进入括号后一直生效，直到右括号为止，可以嵌套。
> 每首歌也能通过 `octave_map` 给 `【】`、`{}` 之类的括号单独指定偏移。

### 关于「调」

`tonic` 表示 **「简谱里的 `1` 实际发哪个音」**，例如 `tonic="C4"` 就是「写的 `1` 弹出 C4」。

⚠️ **本项目的约定：谱子写什么调就用什么调，不做移调。**
移调（比如把 E 大调挪到 C 大调）虽然能消掉所有升号、让演奏「更好按」，
但那会改变原曲的音高，属于替用户做决定 —— 所以不做。

## 快速开始

```bash
git clone https://github.com/yansuan212/三角洲口琴自动化.git
cd 三角洲口琴自动化
python harmonica_autoplay.py
```

启动后：

1. 左侧分类下拉框筛选曲目（如 `摇滚（5）`），下方列表双击选歌
2. `F7` 开始 / 停止，`F5` 暂停，`F6` 重播，`ESC` 急停
3. 切到游戏窗口，先点一下口琴界面让它获得焦点，再按 `F7`
4. 首次运行若没反应，用管理员身份启动（游戏可能以高权限运行）

热键与速度都可在界面里改，会存进 `config.json`。

## 打包成单文件 exe

```bash
pip install pyinstaller
pyinstaller -F -w -n 口琴自动演奏器 harmonica_autoplay.py
```

产物在 `dist/口琴自动演奏器.exe`。
程序会自动把 `songs.json` / `config.json` 放在 **exe 旁边**（不是临时解包目录），所以换电脑只需带上 exe + 这两个 json。

## 项目结构

```
harmonica_autoplay.py    主程序：GUI + 输入模拟 + 简谱解析 + 分类管理
harmonica_song.py        离线音频合成（试听用）
songs.json               曲库（38 首，含分类）
config.json              热键 / 速度 / 循环等设置

add_*.py                 各批曲目的导入脚本（保留用于追溯与重导入）

set_categories.py        批量为曲目写分类
```

## 自己加歌

1. 在 `群谱子/` 放简谱（txt / 图片 / PDF 都行）
2. 照着 `add_fuqin.py` 写一个导入脚本：把简谱正文读出来，填 `tonic`、`bpm`、`category`
3. 跑一次，再跑 `python rebuild_rhythm.py` 把节奏补齐
4. 想先听效果：`python preview_song.py "歌名"` → mp3 落在 `试听/`

也可以直接在 GUI 里「新增曲目」手输简谱。

## 已知限制

- 只支持 **Windows**（依赖 `SendInput` 发扫描码）
- 部分游戏有输入保护，需要 **以管理员权限运行**，或游戏开无边框窗口
- 简谱得自己准备，程序只负责「照着弹」，不会自动扒谱
- 曲库里的谱是照着谱面人工誊写的，个别小节可能有出入，欢迎提 issue 指正
